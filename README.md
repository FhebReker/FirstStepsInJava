# ICS3U - Introduction to Computer Science (Java)
Coursework completed for Grade 11 Computer Science (ICS3U).

This repository contains eight major Java assignments that progressively develop skills in programming fundamentals, problem solving, object-oriented design, file handling, graphical programming, and data processing.

### Technologies
- Java
- Object-Oriented Programming (OOP)
- Java Swing
- File I/O
- Arrays
- Methods and Modular Programming
- String Manipulation
- Conditional Logic and Loops
